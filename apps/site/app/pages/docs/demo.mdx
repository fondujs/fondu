[demo.fondu.dev](https://demo.fondu.dev) is a Fondu app that shows Fondu's features, one page each,
with the code that makes it work. Its source is [apps/demo](https://github.com/fondujs/fondu/tree/main/apps/demo) in the
Fondu repository.

## What it shows

Its menu is grouped by what you would be doing:

- **Routing**: routes and actions, redirects, a page in three languages, the error pages.
- **Forms & requests**: forms with validation, file uploads, flash data, HTTP routes for API clients.
- **Data loading**: props, shared props.
- **Navigation**: links and forms in place, Back, pending state, asset versioning.
- **Rendering**: server-side rendering, and pages rendered in the browser only.
- **Auth**: an account, and an admin area.

Each page says what it demonstrates, which part is Fondu's or Hono's, and which API it uses, so the demo
doubles as a set of working examples.

## What it is built with

- Cloudflare Workers, with a D1 database through Drizzle ORM
- Better Auth for accounts: sign-in, sessions, an admin role
- coss ui (Base UI and Tailwind CSS) for the interface
- Paraglide JS for the languages

The data goes back to its first state every six hours.
