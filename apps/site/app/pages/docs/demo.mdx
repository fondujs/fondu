[demo.fondu.dev](https://demo.fondu.dev) is a Fondu app that shows every Inertia feature, one page each, with the
code that makes it work. Its source is [apps/demo](https://github.com/fondujs/fondu/tree/main/apps/demo) in the
Fondu repository.

## What it shows

- **Inertia's features**: props, partial reloads, deferred props, merging props, infinite scroll, once props, forms
  with validation and Precognition, redirects, asset versioning, history encryption, server-side rendering.
- **Fondu's**: routes and actions, HTTP routes for API clients, navigation, the error pages, an account, and an admin
  area that renders in the browser only.

Each page says what it demonstrates and which API it uses, so the demo doubles as a set of working examples.

## What it is built with

- Cloudflare Workers, with a D1 database through Drizzle ORM
- Better Auth for accounts: sign-in, sessions, an admin role
- coss ui (Base UI and Tailwind CSS) for the interface

The data goes back to its first state every six hours.
