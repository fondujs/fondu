## `fondu`

The server's API, for `app/server.ts`, routes and middleware.

### `createApp()`

`createApp(options?)` returns the Hono app made of `app/routes/`.

| Option          | Is                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| `document`      | the HTML around pages, `({ head, body, c, nonce })` to JSX or a string: [The document](/docs/document) |
| `trailingSlash` | `'trim'` (default: `/users/` redirects to `/users`) or `'append'`                                      |
| `csrf`          | `hono/csrf`'s options, or `false`                                                                      |
| `bodyLimit`     | the largest request body in bytes (default 10 MB, then 413: `hono/body-limit`), or `false`             |
| `secureHeaders` | `hono/secure-headers`' options, or `false`                                                             |

The Content Security Policy by default: `default-src 'self'`; scripts of the site or with the request's nonce (a JSX
document's scripts have it); inline styles (React's style attributes); `data:` images and fonts;
`object-src 'none'`; `base-uri 'self'`. A directive of yours replaces that one only:

```ts
createApp({
  secureHeaders: { contentSecurityPolicy: { fontSrc: ["'self'", 'https://fonts.gstatic.com'] } },
})
```

`contentSecurityPolicy: false`: no policy.

### Handlers

| Export                                                 | Is                                                                      |
| ------------------------------------------------------ | ----------------------------------------------------------------------- |
| `defineHandler(...middleware, handler)`                | a route's handler: Hono's `createHandlers`                              |
| `defineHandler.withValidator({ body, query, params })` | the same, with input checked by Standard Schemas: `(c, input) => …`     |
| `defineMiddleware(fn)`                                 | a middleware: Hono's `createMiddleware`                                 |
| `withoutSsr()`                                         | a middleware: these pages render in the browser only                    |
| `ValidationError`                                      | `throw new ValidationError({ field: 'message' })`: back with the errors |

### Responses

| Export                              | Is                                                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `render(c, Page, props?, options?)` | its file's page; options: `status`                                                                   |
| `share(c, props)`                   | props every page of this request gets                                                                |
| `defer(fn)`                         | a prop of `render()` the page gets in a second request: [Deferred props](/docs/pages#deferred-props) |
| `flash(c, data)`                    | data for the next page (`usePage().flash`)                                                           |
| `back(c, fallback?)`                | a redirect to the page the request came from                                                         |

### Types

| Export             | Is                                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `Register`         | declared by the app: `shared` and `flash` type `share()`, `flash()`, `usePage()` ([Type safety](/docs/type-safety))                |
| `RenderOptions`    | the options of `render()`: `{ status? }`                                                                                           |
| `AsJson`           | a type as a page receives it as JSON: `AsJson<Row>` (a `Date` is a string) ([Type safety](/docs/type-safety#props-from-your-data)) |
| `DocumentTemplate` | the type of the `document` option: `(parts) => JSX or string` ([The document](/docs/document))                                     |
| `DocumentParts`    | what a document template gets: `{ head, body, c, nonce }`                                                                          |
| `CreateAppOptions` | the options of `createApp()`, as the table above has them                                                                          |

### Route exports

| Export                                             | Is                                                                                       |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `default` (in a `.tsx` file)                       | the page, rendered by `render()`, or on GET without a loader                             |
| `loader` (in a `.tsx` file)                        | GET                                                                                      |
| `action` (in a `.tsx` file)                        | POST                                                                                     |
| `actions = { name }` (in a `.tsx` file)            | POST `?name` (`action` or `actions`, not both)                                           |
| `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS` | HTTP handlers (in a `.ts` file)                                                          |
| `prerender`                                        | `true`, `false` or a function listing params: a [static page](/docs/static-pages)        |
| `params`                                           | `{ name: ['value', …] }`: the [values a param takes](/docs/routes#the-values-of-a-param) |
| `default` (in `_middleware.ts`)                    | the directory's middleware                                                               |

### Route files

| File                   | Is                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `name.tsx`, `name.mdx` | a page and its handlers ([what each exports](/docs/routes#what-a-route-file-exports)) |
| `name.ts`              | server code only: HTTP handlers                                                       |
| `_middleware.ts`       | the middleware of its directory and below                                             |
| `_layout.tsx`          | the [layout](/docs/layouts) of the pages in its directory and below                   |
| `_error.tsx`           | the [error page](/docs/errors)                                                        |
| `_name.tsx`, `_name/`  | not a route: a file, or a directory, starting with `_`                                |
| `name.test.tsx`        | not a route: a test (`*.test.*`, `*.spec.*`)                                          |

## `fondu/client`

Hooks, `<Deferred>` and `href()` run on the server too, in a page's server render (so does `RequestError`, a class).
`request()`, `reload()`, `navigate()`, `closeShallow()` and `loadDocument()` are for the browser, from events and effects: on
the server they throw.

| Export                                             | Is                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `href(path, params?)`                              | a URL of `app/routes/`, typed: `href('/users/:id', { id: 7, query?, hash? })` ([Type safety](/docs/type-safety#urls))                                                                                                                                                                               |
| `usePage()`                                        | the page on screen, a `Page`: `component` (its id: its route file's path), `props`, `url` (path and query), `flash`                                                                                                                                                                                 |
| `useNavigation()`                                  | the navigation on its way: `{ state, to, form }`, `state` `'idle'`, `'loading'`, `'submitting'` or `'failed'` (a form not sent)                                                                                                                                                                     |
| `useForm(schema?)`                                 | a form checked in the browser by its action's schema: `{ form, field, errors, submitting, failed }` ([Forms](/docs/forms#the-same-schema-in-the-browser))                                                                                                                                           |
| `reload({ only? })`                                | the page's props again, its state and scroll position kept; `only: ['stats']`: those props alone, quietly                                                                                                                                                                                           |
| `<Deferred data fallback failed>`                  | children once the deferred props `data` are there, `fallback` while asked for, `failed` if they could not be had                                                                                                                                                                                    |
| `navigate(href, { replace?, keep?, transition? })` | goes to `href` as a link would: a page in place, anything else as a document; `keep`: the page keeps its state and scroll, as `reload()` does; `transition`: `true` or the types to add, a [view transition](/docs/navigation#view-transitions) ([Navigation](/docs/navigation#navigating-in-code)) |
| `navigate(href, { shallow: true, replace? })`      | changes the page on the screen to a page URL of this app, keeping its component and props, asking for nothing, with no transition; `usePage().url` follows ([Shallow navigation](/docs/navigation#shallow-navigation))                                                                              |
| `closeShallow(to)`                                 | closes what a shallow navigation opened, one step: Back, or `to` in place of the current entry ([A dialog or a drawer](/docs/navigation#a-dialog-or-a-drawer))                                                                                                                                      |
| `loadDocument(href)`                               | a document load, for what a page can't change in place                                                                                                                                                                                                                                              |
| `request(path, options?)`                          | a typed call to a `.ts` route from the browser: `request('/api/users/:id', { id: 7, method?, query?, body? })`; a non-2xx answer throws ([Routes](/docs/routes#calling-a-route-from-the-browser))                                                                                                   |
| `RequestError`                                     | what `request()` throws for a non-2xx answer: `status`, `data` (the parsed body), `response`                                                                                                                                                                                                        |

### Types

| Export       | Is                                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| `Errors`     | the type of a page's `errors` prop: field name to message                                                 |
| `Href`       | the URLs `href()` takes: each route's pattern, and `pattern?action` for its actions                       |
| `Navigation` | what `useNavigation()` returns: `{ state, to, form }`                                                     |
| `Page`       | what `usePage()` returns: `{ component, props, url, flash }`; `Page<P>` types `props` as `P` and `errors` |

`fondu/client/internal` is the Vite plugin's entry, for the plugin only: an app does not import it, and it may change in
any release.

## `fondu/vite`

The Vite plugin: `fondu(options)`. The options are checked when the plugin is created: `target` is required, and an unknown option fails. There is
no `port` option: the built server (Bun and Node) listens on `PORT`, else 3000.

| Option            | Is                                                                                                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `target`          | `'bun'`, `'cloudflare'` or `'node'`                                                                                                                         |
| `ssr`             | `false`: pages render in the browser only                                                                                                                   |
| `prerender`       | `true`: write the chosen pages as [static files](/docs/static-pages)                                                                                        |
| `progress`        | the navigations' progress bar: `{ color, delay, forms }`, or `false`                                                                                        |
| `viewTransitions` | `true`: every navigation runs inside the browser's view transition by default, and a link or call opts out; [navigation](/docs/navigation#view-transitions) |
| `react`           | passed to [`@vitejs/plugin-react`](https://github.com/vitejs/vite-plugin-react/tree/main/packages/plugin-react) (its `include` has `.mdx` by default)       |

### Types

| Export            | Is                                                           |
| ----------------- | ------------------------------------------------------------ |
| `FonduOptions`    | the options of `fondu()`, as the table above has them        |
| `ProgressOptions` | the `progress` option's object: `{ color?, delay?, forms? }` |
