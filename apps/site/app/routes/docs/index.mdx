Fondu is a small meta-framework for full-stack React apps, built on [Hono](https://hono.dev) and
[Vite](https://vite.dev). It runs on Bun, Cloudflare Workers and Node.

## Routes and pages

An app has two kinds of files. **Routes** in `app/routes/` are Hono handlers that run on the server; the file path is
the URL. **Pages** in `app/pages/` are React components. A route renders a page by name, with its props:

```ts
// app/routes/users/[id].ts: GET /users/7
export const loader = defineHandler.withValidator({ params })(async (c, { params }) =>
  render(c, 'users/show', { user: await getUser(params.id) }),
)
```

```tsx
// app/pages/users/show.tsx: the component's props are the page's props
export default function Show({ user }: { user: User }) {
  return <h1>{user.name}</h1>
}
```

The first request gets the page rendered on the server. From then on, links and forms are plain `<a>` and `<form>`:
Fondu's client, on the browser's [Navigation API](https://developer.mozilla.org/en-US/docs/Web/API/Navigation_API),
asks the same route for the next page's name and props as JSON, and React swaps the page in place. There is no API to
write for your pages and no client-side router to keep in sync with the server: the routes are the only router.
Without the Navigation API, links and forms load documents, and everything still works.

## Who does what

| Part                                                                                                                               | Done by                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| HTTP, middleware, CSRF protection, security headers                                                                                | Hono and its middleware                                         |
| Dev server and production build                                                                                                    | Vite, with `@hono/vite-dev-server` or `@cloudflare/vite-plugin` |
| `routes/`, pages and layouts, the client, forms' errors and flash data, typed pages and URLs, the document, error and static pages | Fondu                                                           |

So most of what you write on the server is Hono's API, and its docs apply as they are. The pages here cover what Fondu
adds.
